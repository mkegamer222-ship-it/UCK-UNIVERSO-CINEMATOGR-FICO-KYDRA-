# Capturas

| Arquivo | O que mostra |
| --- | --- |
| `reference-horizon-play.png` | Launcher do Horizon, página Play — a referência de layout do herói. |
| `reference-horizon-versions.png` | Lista de versões em linhas com divisor. |
| `reference-horizon-settings.png` | Ajustes com linhas numeradas e controle à direita. |

As capturas são do launcher oficial do Horizon (projeto `horizon-rust/horizon`,
LGPL-3.0-or-later), guardadas aqui só como referência visual do que o Kydra segue.

Para capturar as telas do Kydra: `npm start`, abra `http://localhost:8787` e salve
`#/play`, `#/versions`, `#/settings` como `play.png`, `versions.png`, `settings.png`.
